**Среда:** Ubuntu, Python 3.14.4

## C1. TrackedLock

Реализована проверка взаимоблокировки с использованием `TrackedLock`.

При тестировании программы `transfer_tracked.py` получен результат:

```text
cashier1 Обнаружена взаимоблокировка: цикл ожидания
TrackedLock test completed
```

Программа обнаружила циклическое ожидание блокировок и завершила проверку.

## C2. Обедающие философы

Реализованы и протестированы три варианта:

1. Naive — наивный захват вилок.
2. Ordered — захват вилок в установленном порядке.
3. Waiter — использование семафора, ограничивающего число одновременно участвующих философов до четырёх.

### Результаты

| Метод | Количество приёмов пищи | Зависшие потоки | Максимальное ожидание |
|---|---|---|---|
| Naive | 0, 0, 0, 0, 0 | 5 | 0 с* |
| Ordered | 10, 10, 10, 10, 10 | 0 | 0.000013 с |
| Waiter | 10, 10, 10, 10, 10 | 0 | 0.000006 с |

*В наивном варианте значение 0 не означает отсутствие ожидания: потоки остались заблокированными.

## Вывод

В ходе работы изучены взаимоблокировки в многопоточных программах.

`TrackedLock` обнаруживает циклическое ожидание ресурсов.

Наивный алгоритм обедающих философов приводит к взаимоблокировке, тогда как упорядоченный захват ресурсов и использование семафора предотвращают её в проведённых тестах.

В безопасных вариантах каждый философ успешно завершил 10 приёмов пищи.
